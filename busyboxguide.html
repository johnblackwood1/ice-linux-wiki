Ice Linux | Wiki | How to fix commands not working

!!! For this guide you have to be logged into root! Your command line should have a # if logged into root. !!!

This guide/tutorial shows you how to:

1. Installing busybox (so commands like ls and cd work).

2. Test busybox.


Step 1: installing busybox

You may be asking "How do you install busybox?". Its really simple

      /bin/busybox --install -s /bin

Step 2: Testing busybox (to see if it succesfully installed

You may be asking "How do i know if busybox installed?". This step is gonna tell you how to test it.

      ls

This should output all the files in the directory. Boom! You have both installed busybox (for commands) and tested it!
